IBFC — MAPA DF/ENTORNO + SINCRONIZAÇÃO AUTOMÁTICA TSE

PACOTE ÚNICO CONSOLIDADO
Reúne o mapa, a ampliação do Entorno e a automação. Contém apenas arquivos do módulo novos/alterados. Não é uma substituição completa do portal IBFC.
Não precisa aplicar os ZIPs anteriores. Se já os instalou, aplique este por cima, preservando as pastas.

PASSO A PASSO
1. Extraia e copie as pastas na raiz do GitHub IBFC. Inclua as pastas ocultas .github e o arquivo .npmrc.
2. No Supabase usado pelo IBFC → SQL Editor, execute SOMENTE o SQL completo:
   supabase/migrations/20261009_ibfc_map_and_tse_sync.sql
   Ele instala/atualiza o mapa e a automação, preserva dados existentes e recarrega o schema cache. Requer admin_profiles da base do portal.
3. GitHub → Settings → Secrets and variables → Actions → New repository secret:
   SUPABASE_URL = URL do mesmo Supabase do IBFC.
   SUPABASE_SERVICE_ROLE_KEY = chave JWT service_role desse projeto (não use chave anon/publicável).
4. Crie um token GitHub fine-grained restrito ao repositório IBFC com permissão Actions: Read and write.
5. Vercel → Settings → Environment Variables:
   GITHUB_TSE_TOKEN = token do passo anterior (somente servidor).
   GITHUB_TSE_REPOSITORY = tecnologiaagilize-dotcom/ibfc (ajuste se necessário).
   GITHUB_TSE_REF = main (ajuste à branch padrão com o workflow instalado).
   Mantenha as variáveis atuais do Supabase e Google Maps. Nenhum token deve ter prefixo NEXT_PUBLIC.
6. Faça novo deployment. Em Administrador → Mapa eleitoral DF e Entorno, selecione 2022, DF + GO e clique em Sincronizar bases oficiais. Depois solicite 2026.

EXECUÇÃO
A Vercel inicia a tarefa e o GitHub Actions baixa/extrai/processa os arquivos. Você pode fechar a página. O painel acompanha progresso, histórico e cancelamento. A carga anterior permanece consultável se a nova falhar. Dados incompletos não entram no mapa. Recursos ainda não publicados são sinalizados como pendência/carga parcial.
Não é uma sincronização recorrente agendada: cada carga é iniciada pelo administrador. A importação manual continua opcional.

VERIFICAÇÃO DESTA ENTREGA
- Build Next.js, 9 testes de leitura/cálculos e 5 testes do worker aprovados.
- PostgreSQL de teste: permissões, token privado, fila, cancelamento, carga atômica, preservação da versão anterior após falha e repetição do SQL aprovados.
- Navegador: iniciar sem upload, persistência após recarregar a página, progresso, cancelar, recarga do catálogo e largura mobile aprovados.
- Catálogo real TSE: recursos de votação 2022 e locais 2026 localizados; votação por seção 2026 ainda não localizada nesta consulta do catálogo. Nenhum resultado real foi importado no Supabase de produção.
- GitHub/Vercel/Supabase de produção não foram alterados. O botão só inicia a carga após a configuração dos passos acima.
