IBFC — ATUALIZAÇÃO CONSOLIDADA: MAPA LEAFLET + OPENSTREETMAP E SINCRONIZAÇÃO TSE

Este ZIP contém os arquivos do módulo atualizado, não o portal completo.
Copie as pastas na raiz do repositório IBFC, preservando os caminhos.
Inclua public/vendor/leaflet-1.9.4: biblioteca local, estilos, imagens e licença.
Inclua .github/workflows/ibfc-tse-sync.yml caso ainda não esteja instalado.

MAPA
Não exige chave Google, cartão ou nova dependência npm.
As variáveis antigas NEXT_PUBLIC_GOOGLE_MAPS_API_KEY/MAP_ID não são utilizadas.
As variáveis .env.electoral.example são opcionais; vazias usam o OpenStreetMap.
Faça commit e novo deployment na Vercel; acesse /admin/mapa-eleitoral.
Conserva locais/seções, filtros DF/GO/MG, cores, comparação 2022/2026 e CSV/PDF.
Locais sem coordenadas continuam na tabela. O fundo usa tiles públicos OSM,
com atribuição visível e cache do navegador; capacidade não é ilimitada.

BANCO
Se já executou 20261009_ibfc_map_and_tse_sync.sql, NÃO precisa executá-lo
novamente para trocar o mapa. Nenhuma migração nova nesta atualização.
Para a primeira instalação do módulo, execute esse único SQL consolidado
no Supabase correto; requer admin_profiles e auth.users da base do portal.

SINCRONIZAÇÃO TSE
Permanece no mesmo fluxo: Vercel inicia, GitHub Actions processa em segundo plano.
Requer Secrets GitHub SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY (JWT service_role)
e variáveis de servidor Vercel GITHUB_TSE_TOKEN, GITHUB_TSE_REPOSITORY,
GITHUB_TSE_REF. Consulte docs/IBFC-SINCRONIZACAO-TSE.md.
Não substitua suas variáveis Supabase atuais por arquivos de exemplo.
Só estarão disponíveis votos publicados e importados; não há dados reais
pré-carregados nem mudança aplicada automaticamente à produção.

Documentação completa: docs/IBFC-MAPA-ELEITORAL.md.
Este pacote substitui os ZIPs anteriores deste módulo; não copie versões antigas por cima.
